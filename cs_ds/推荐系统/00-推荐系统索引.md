# 推荐系统索引

本目录记录一套以工业信息流场景为主的推荐系统课程：既有可检索的 Markdown 全量笔记，也有按主题拆分的八份 PDF，并新增一份面向 RecFlow 代码阅读的 PyTorch 基础笔记。建议把它看成机器学习之后的应用与系统化延伸：模型目标不只是离线拟合，而是要在召回、排序、重排、实验和业务指标的整体链路中工作。

## 学习主线

1. 工程准备先读 [[cs_ds/推荐系统/PyTorch初识|PyTorch 初识]]，建立“Tensor -> Model -> Loss -> Autograd -> Optimizer”的训练闭环，并能沿 shape 追踪推荐模型中的 batch、序列、embedding、负样本和候选维度。对应 [[00-Wiki/Concepts/PyTorch训练循环|PyTorch 训练循环]]。
2. 再读 [[cs_ds/推荐系统/第一部分：推荐系统基本概念.pdf|第一部分：基本概念]]，明确曝光、点击、交互、DAU、留存和北极星指标，并理解离线实验、小流量 A/B 测试、全量上线的区别。
3. 进入 [[cs_ds/推荐系统/第二部分：召回.pdf|第二部分：召回]]：从 ItemCF / UserCF 的相似度开始，再理解矩阵补全、双塔、Deep Retrieval 与曝光过滤。对应 [[00-Wiki/Concepts/协同过滤|协同过滤]]、[[00-Wiki/Concepts/双塔模型|双塔模型]]。
4. 阅读 [[cs_ds/推荐系统/第三部分：排序.pdf|第三部分：排序]] 与 [[cs_ds/推荐系统/第四部分：交叉结构.pdf|第四部分：交叉结构]]：掌握多目标预估、分数融合、粗排/精排，以及 FM、DCN、LHUC、SENet/Bilinear 等特征交叉路线。对应 [[00-Wiki/Concepts/学习排序|学习排序]]。
5. 用 [[cs_ds/推荐系统/第五部分：用户行为序列建模.pdf|第五部分：用户行为序列建模]] 衔接 Last-N、DIN 与 SIM；再以 [[cs_ds/推荐系统/第六部分：多样性.pdf|第六部分：多样性]] 理解 MMR、DPP 和打散策略为何属于“重排”问题。
6. 最后学习 [[cs_ds/推荐系统/第七部分：物品冷启动.pdf|第七部分：物品冷启动]] 和 [[cs_ds/推荐系统/第八部分：涨指标的方法.pdf|第八部分：涨指标的方法]]，把新物品探索、特殊人群、线上学习和指标增长放回可控实验体系。对应 [[00-Wiki/Concepts/A-B测试|A/B 测试]]。

## 复习抓手

- 画出“用户与物品特征 -> 多路召回 -> 粗排 -> 精排 -> 重排 -> 展示 -> 行为反馈”的闭环，并在每一层写出输入、输出、计算预算与可观察指标。
- 对任一模型改动，依次回答：改的是召回覆盖、排序准确性还是多样性？离线用什么指标筛选？线上用什么分桶与护栏指标验证？
- 区分“预测点击率高”与“业务指标一定增长”。前者是模型局部目标，后者还取决于指标融合、用户体验、延迟效应和实验设计。
- 读训练代码先给每个 Tensor 标注 `[B, L, D, N, K]` 的维度语义，再检查 device、dtype、广播、loss 的标量化以及 `zero_grad -> backward -> step`。
