# 数科导索引

数科导是进入数据科学实践的起点。本目录现以 Data 100 中文教程为主线：从提出问题、获取和理解数据，到回归、分类、优化与完整案例；原有网络、爬虫、预处理和可视化笔记作为相应阶段的工具补充。

## 学习主线

1. [[cs_ds/数科导/data100/01-生命周期中文讲解|01 生命周期]]：把现实问题转成数据问题，区分描述、推断、预测与因果，并明确数据来源和适用范围。
2. [[cs_ds/数科导/data100/02-表格数据中文讲解|02 表格数据]] -> [[cs_ds/数科导/data100/03-理解数据中文讲解|03 理解数据]]：掌握表格结构、变量类型、分布、可视化和探索性检查。
3. [[cs_ds/数科导/data100/04-其他数据源中文讲解|04 其他数据源]]：将网页、文本、地理等非表格来源转化为可分析数据；需要采集实践时回看 [[cs_ds/数科导/2.数据获取与爬虫|数据获取与爬虫]]。
4. [[cs_ds/数科导/data100/05-线性建模中文讲解|05 线性建模]]：从特征、损失、拟合到诊断，衔接 [[00-Wiki/Concepts/回归模型|回归模型]] 和 [[00-Wiki/Concepts/最小二乘法|最小二乘法]]。
5. [[cs_ds/数科导/data100/06-分类优化中文讲解|06 分类与优化]]：理解概率、阈值、交叉熵、混淆矩阵、PR/ROC、梯度下降及文本分类案例，之后进入 [[cs_ds/机器学习/00-机器学习索引|机器学习]]。

## 复习抓手

- 每个项目先写清“一行代表什么、正类/目标变量是什么、数据从哪里来、部署时能否得到同样特征”。
- 回归要检查残差与泛化；分类要把概率估计、阈值决策、错误代价和评估指标分开讨论。
- 所有预处理、特征工程和阈值选择只在训练数据内部完成，测试集只用于最终检查。
- 如果要把离线模型用于产品策略，补做 [[00-Wiki/Concepts/A-B测试|A/B 测试]]，不要用训练集或单一离线分数直接代替线上结论。
